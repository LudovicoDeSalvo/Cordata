# Agent memory landscape (researched 2026-09-29)

Purpose: decide what "memory" means for Cordata. Subagent web research; numbers are author-reported unless stated; [U] = unconfirmed.

## TencentDB Agent Memory

- https://github.com/TencentCloud/TencentDB-Agent-Memory, MIT, ~27.5k stars. v2.0.0 stable 2026-08-03; v2.0.1 2026-08-25; v2.0.2-beta.3 2026-09-21 (MongoDB backend, experimental). Parallel v1.0.x line (local single-user, SQLite + sqlite-vec) [U].
- v2 architecture: Memory Core :8420 (Chat Memory L0→L3, Skills), Memory Knowledge :8424 (Wiki, CodeGraph), Memory Proxy :8096, Panel/Hub :8125. Retrieval BM25 + vector + RRF. `/v3/tools/list` and `/v3/tools/call` confirmed; header `x-tdai-user-key`.
- Proxy injection: auth → sessionInit → injection into system prompt → forward. Only off switch is `PROXY_FULL_STACK=0` passthrough. Direct Core/Knowledge HTTP + TS/Python SDKs exist.
- Requires OpenAI-compatible LLM endpoints (two parameter sets). CodeGraph private-repo SSH "still being refined".
- Maturity: early. Issues #1523 (transient LLM failure permanently loses session content, 2026-09-26), #1543 (L2 blocks grow monotonically), #1544 (install ships placeholder values). Third-party review verdict "pilot, don't standardize" (2026-08-09).

Decision input: not a defensible core dependency for a local-first solo tool.

## Alternatives (temporal validity / provenance / deletion / code-aware / local)

- Mem0 (Apache-2.0): ADD-only extraction, no invalidation; graph memory paid only [U]; local yes. Negative on VibeMemBench.
- Zep/Graphiti (Apache-2.0): bitemporal facts (valid_at/invalid_at), episode-linked provenance, invalidation not deletion; needs Neo4j/FalkorDB + capable LLM. Zep CE deprecated.
- Letta / letta-code (Apache-2.0): self-editing memory blocks, git-based "Context Repositories" (Feb 2026), sleep-time compute; local yes.
- Hindsight (MIT, v0.10.2 2026-09-29): world facts / experiences / observations / mental models; occurred_start/end + staleness; provenance per doc; single container with embedded Postgres; harness integrations incl. Claude Code, Codex, opencode.
- Supermemory (MIT core): temporal contradiction resolution, auto-forget expiry, AST-aware code chunking; single-binary self-host.
- Cognee (Apache-2.0, v1.6.1 2026-09-24): graph+vector pipeline, indexes repos into symbol/dependency graph, `forget`, fully offline (Kuzu/LanceDB).
- A-MEM, LangMem, Honcho: research-grade or framework-bound; none of the four properties.
- New: Elastic Atlas (Jun 2026), Agent Memory Challenge cycle 2 (Sep 2026).

## Research Jun–Sep 2026

- "Useful Memories Become Faulty When Continuously Updated by LLMs" (2605.12978, v2 2026-08-29): LLM-rewritten consolidated memory rises then degrades below no-memory; GPT-5.4 fails 54% of previously solved ARC-AGI tasks after consolidation from ground truth; retain-raw-episodes matched or beat consolidation.
- VibeMemBench (2609.23570, 2026-09-20): 111 SWE-bench V2 targets; Mem0, SimpleMem, MemoryOS, A-MEM: 11/12 solver-system pairs fail to beat memory-off (Mem0 −4.3pp, A-MEM −4.0pp). Injecting verified experience directly: +1.1 to +4.5pp. 69% of failures = "form degradation" (fix pattern buried/overgeneralized).
- EA-Graph (2608.04278): artifact-anchored verification claims that become "unprovable" when code drifts beat prose notes in 7/7 worlds on Haiku (ceiling on Sonnet).
- MERIT (2609.05441): memory lifts dependent tool tasks 0.00→0.55–1.00; embedding retrieval collapses on updated facts (0.30–0.95) while update-on-write stores hold 0.70–1.00; agents act on correctly retrieved values only 55% of the time.
- Compaction Cliff (2608.22752): Claude Code `/compact` keeps 53% of safety rules after 1 round, 10% after 5. CliffCompaction (2609.26779, 2026-09-22): truncate-only, never re-compact compacted text; −50% cost, +10pp Terminal-Bench.
- Zero-Mem (2607.29377): no LLM calls for memory ops; code withheld. Agent Zero Memory (2608.29606): every item carries origin/timestamp/evidence pointer; LongMemEval 95.6%; chat only. WhenLoss (2605.24579): 4/6 baselines write-side bottlenecked. LongMemEval-V2 (2605.12493): coding-agent-over-trajectories 72.5% vs RAG 48.5%. SWE-ContextBench (2602.08316): well-summarized prior trajectories help hard tasks; poor selection hurts.

## What shipping coding agents do (Sep 2026)

- Claude Code: CLAUDE.md/AGENTS.md + `.claude/rules/`; auto memory (typed notes user/feedback/project/reference in `~/.claude/projects/<repo>/memory/`), first 200 lines/25KB loaded; explicitly skips anything derivable from code. No code graph.
- Codex: AGENTS.md + automatic background memories (`~/.codex/memories/`, global, summaries + durable entries + evidence). No code graph.
- Cursor: auto-proposed sentence memories per repo/user; local grep index, not graph.
- Devin: Knowledge deprecated → Skills in Plugins; DeepWiki repo index (50k+ repos). Windsurf → "Devin Desktop", per-workspace auto-memories.
- Cline: Memory Bank is a `.clinerules` methodology.

## Defensible local-first defaults

1. Checked-in markdown instructions + raw session/episode log kept verbatim; consolidation explicit and gated, never per-turn rewrite.
2. Update-on-write structured fact store with validity windows + provenance pointers (Graphiti-style invalidation; EA-Graph artifact anchoring).
3. Repo-derived knowledge regenerated from code, never memorized (Claude Code's own rule; VibeMemBench form degradation).

Not defensible as default: TencentDB (early, data-loss bugs, proxy injection), Mem0 OSS (ADD-only, negative on coding).
